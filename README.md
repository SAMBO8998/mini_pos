# 🛒 Mini Mart POS

Mini Mart POS is a simple Point of Sale (POS) system built with PHP, MySQL, and Bootstrap 5.

This project allows users to manage products, categories, sales, orders, and stock through a simple web-based interface.

## 📌 Features

- 🔐 User Login and Logout
- 📊 Dashboard
- 🛍️ Product Management
- 📂 Category Management
- 💰 Point of Sale (POS)
- 🧾 Sales Receipt
- 📋 Order History
- 📦 Stock Management
- 🔎 Search Products and Orders
- 🏷️ Filter Products by Category

## 🛠️ Technologies

- HTML5
- Bootstrap 5
- JavaScript
- PHP
- MySQL
- phpMyAdmin
- XAMPP
- Font Awesome
